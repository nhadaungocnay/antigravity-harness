# Harness — The Architecture Factory for Antigravity

**English** | [Tiếng Việt](README-vi.md)

> **Harness is an architecture factory for Google Antigravity.** Say **"build a harness for this project"** and it turns your domain description into a dynamic execution plan (`task.md`), Persona Knowledge Items (`.agent/knowledge/`), and specialized skills (`.agent/skills/`) — utilizing the hybrid approach of Single-Agent Role Switching and Subagent Spawning.

## Overview

Harness leverages Antigravity's artifact-driven execution and Knowledge Items (KIs) to decompose complex tasks into coordinated sequences. It automatically generates Persona definitions (`.agent/knowledge/`) and skills (`.agent/skills/`) tailored to your domain.

## Key Features

- **Hybrid Execution Architecture** — Focuses on **Single-Agent Role Switching** (sequentially loading Persona KIs) for stability, and **Explicit Subagents** for parallel Fan-out/Fan-in patterns.
- **Agent Design Patterns** — 6 architectural patterns: Pipeline, Fan-out/Fan-in, Expert Pool, Producer-Reviewer, Supervisor, and Hierarchical Delegation.
- **Skill Generation** — Auto-generates skills optimized for Antigravity's terminal and scripting capabilities.
- **Artifact-Driven Orchestration** — Orchestration is entirely managed via `task.md` and Knowledge Items rather than hidden agent memory states.

## Workflow

```
Phase 1: Domain Analysis
    ↓
Phase 2: Hybrid Architecture Design (Sequential Persona Switch vs Parallel Subagents)
    ↓
Phase 3: Persona Knowledge Generation (.agent/knowledge/)
    ↓
Phase 4: Skill Generation (.agent/skills/)
    ↓
Phase 5: Artifact Integration (task.md & GEMINI.md)
    ↓
Phase 6: Validation & Testing
```

## Installation

### Via Antigravity CLI

```shell
# Scaffold the Harness into your Antigravity Agent environment
agy install harness
```

### Direct Installation

Copy the harness skills directory to your agent's skills folder:
```shell
cp -r skills/harness ~/.agent/skills/harness
```

## Usage

Trigger Antigravity via a slash command or natural language prompt:

```
/harness Build a harness for this project
Design an architecture team for this domain
Set up a harness
```

### Execution Modes (Hybrid Approach)

| Mode | Description | Recommended For |
|------|-------------|-----------------|
| **Single-Agent Role Switching** (default) | Main Agent sequentially adopts Personas via Knowledge Items in `task.md`. | Pipeline, Producer-Reviewer, Expert Pool. |
| **Subagent Spawning** | Main Agent acts as Supervisor and spawns parallel subagents. | Fan-out/Fan-in, highly parallel independent tasks. |

```
└── .agent/

```
